# Release Ownership

| Field | Owner |
|---|---|
| Release decision owner | INFINICUS LLC designated product owner |
| Deployment owner | INFINICUS LLC designated release operator |
| Rollback owner | INFINICUS LLC on-call release operator |
| Incident commander | INFINICUS LLC designated incident lead |
| Security sign-off | INFINICUS LLC security owner |
| Commercial sign-off | INFINICUS LLC product owner |

The deployment owner monitors CI through Block 2H. The rollback owner may immediately roll back either Worker when a rollback trigger occurs. Database changes use a reviewed forward migration or manual repair.
